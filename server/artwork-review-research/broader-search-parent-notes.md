# Additional primary gallery pass

Checked complete public Discogs release galleries for the remaining hard vinyl slots, downloaded all 45 images, and visually inspected them. Cover squares and insert pages were excluded. No artwork was edited.

- [Curtain Call: The Hits, 2024 blue vinyl](https://www.discogs.com/release/34962776): selected two complete real disc photographs, sides A and B. The [older black edition](https://www.discogs.com/release/3419793) supplied only center-label closeups, which were not added. Original Curtain Call confirmed, not Curtain Call 2.
- [Planet Her, 2026 translucent blue reissue](https://www.discogs.com/release/37722192): selected the complete standalone blue vinyl photo. The [original black LP gallery](https://www.discogs.com/release/23363297) contained only labels and packaging, excluded.
- [2014 Forest Hills Drive, original black 2LP](https://www.discogs.com/release/6736792): a clear straight-on label scan is a useful fallback, but complete-circle vinyl photographs are still missing.

Release status here follows the community physical-release records, not a claim of image ownership. Exact downloaded originals and full metadata JSON are retained under broader-search-parent-downloads/.
